# 내 차에서 나 좀 꺼내줘! — 자동차 방탈출

자동차 안의 단서를 찾아 3단계 퍼즐을 풀고 탈출하는 웹게임입니다. 코미디 분위기의 스토리와 사물 중심의 탐색을 제공합니다.

[배포된 게임 플레이](https://elaborate-cassata-f398fd.netlify.app/)

## 실행

`index.html`을 브라우저에서 직접 열면 플레이할 수 있습니다. HTML, CSS, JavaScript와 SVG 그림이 하나의 파일에 포함되어 있어 외부 라이브러리나 이미지 다운로드, 패키지 설치가 필요하지 않습니다. 인터넷 없이도 작동합니다.

로컬 서버를 사용하려면 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/game/locked-car-escape/`에 접속합니다.

## 조작 방법

- 화면 속 사물을 클릭하거나 터치해 조사합니다. 마우스를 올리면 상호작용 영역이 강조됩니다.
- 룸미러를 누르면 뒷좌석으로 이동합니다. 뒷좌석 위쪽을 누르면 앞좌석으로 돌아옵니다.
- 아래 소지품에서 아이템을 선택한 뒤 사용할 사물을 누릅니다.
- 잠금장치의 숫자 버튼과 입력 버튼으로 정답을 제출합니다.
- 컴퓨터에서는 Tab으로 사물을 선택하고 Enter 또는 Space로 조사할 수도 있습니다.
- `처음부터` 버튼으로 초기화할 수 있습니다. 진행 상태는 새로고침 후 유지되지 않습니다.

## 구성 및 제작 경험

- 3단계 퍼즐: 수납함 → 가방 → 스마트 잠금장치
- 사물 조사, 아이템 획득·선택·사용, 앞뒤 좌석 시점 전환, 탈출 엔딩
- 사용자 피드백에 따라 별도 상호작용 버튼을 제거하고 사물 Hover 강조 및 룸미러 이동 적용
- HTML, CSS, JavaScript, SVG 기반 단일 파일 게임
- ChatGPT를 활용한 스토리·퍼즐 구체화 및 제작

업로드된 `locked_car_escape_share.html`을 `index.html`로 이름만 바꿔 포함했습니다. 게임 코드는 변경하지 않았습니다.

## 동작 확인

Chromium의 데스크톱(1280×900)·모바일 크기(390×844) 화면에서 사물 조사, Hover 강조, 좌석 이동, 오답 처리, 아이템 선행 조건, 세 퍼즐 해결, 탈출 엔딩, 다시 플레이를 확인했습니다. 모바일 크기 검증은 실제 모바일 기기 터치 테스트와 구분됩니다.

실제 플레이 인원 및 평균 탈출 시간은 미측정입니다.


## 기획 및 담당 역할

자동차 내부에 숨겨진 단서를 찾고 3개의 퍼즐을 순서대로 해결해 탈출하는 웹게임입니다. 레이싱 중심의 자동차 게임에서 벗어나 추리와 코미디를 함께 즐기는 경험을 기획했습니다.

### 담당한 일

- 자동차 방탈출 아이디어 제안, 코미디 분위기의 스토리와 3단계 퍼즐 기획
- ChatGPT를 활용한 스토리·퍼즐 구체화 및 HTML, CSS, JavaScript 기반 제작
- 브라우저 플레이를 통한 UI 및 조작 방식 점검

### 피드백과 개선

초기에는 상호작용 버튼이 지나치게 눈에 띄어 탐색의 재미가 부족하다는 피드백을 받았습니다. 별도 버튼을 제거하고, 사물 위에 마우스를 올리면 테두리가 빛나도록 변경했습니다. 백미러 클릭으로 뒷좌석 시점으로 전환하도록 구성하고, 과도한 힌트를 줄여 직접 단서를 찾도록 개선했습니다.

**사용 기술:** HTML, CSS, JavaScript, Hover·Click 이벤트, ChatGPT

**결과:** 사물 중심 상호작용과 시점 전환을 갖춘 3단계 방탈출 게임 제작. 실제 플레이 인원과 평균 탈출 시간은 미측정입니다.

**연결 역량:** 사용자 요구 분석, 피드백 반영, UI/UX 개선
