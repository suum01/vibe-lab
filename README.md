# vibe-lab

바이브 코딩으로 만든 모든 것을 모으는 개인 작업실입니다.

AI와 함께 아이디어를 구체화하고 직접 만들고 실험한 작업들을 기록합니다. 게임을 비롯해 앞으로 만드는 다양한 프로젝트도 종류별 폴더에 정리합니다. 각 프로젝트에는 소스, 실행 방법, 제작 과정과 개선 내용을 함께 남깁니다.

## 프로젝트

| 분류 | 내용 |
| --- | --- |
| [apps](apps/) | 일정과 예상 시간을 순서대로 실행하는 Windows용 차례차례 타이머 |
| [game](game/) | 자동차 방탈출, 현대자동차 수박게임, 인제 카트레이싱 |

## 저장소 구조

```text
vibe-lab/
├── README.md
├── apps/
│   └── sequence-timer/    # Windows 설치형 일정 타이머
└── game/
    ├── README.md
    ├── locked-car-escape/   # 내 차에서 나 좀 꺼내줘!
    ├── hyundai-merge/       # HYUNDAI MERGE
    └── inje-kart-racing/    # 인제 카트레이싱 (소개 · 소스 추가 예정)
```

프로젝트별 소개와 실행 방법은 각 폴더의 README에서 확인할 수 있습니다. 현재 자동차 방탈출과 HYUNDAI MERGE는 소스가 포함되어 있으며, 인제 카트레이싱은 소개와 배포 링크를 정리했습니다.
