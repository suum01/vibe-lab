# vibe-lab

AI를 활용해 자동차를 소재로 만든 웹게임 프로젝트 모음입니다. 게임 기획, 사용자 피드백을 통한 인터페이스 개선, 게임 규칙 설계, 플레이 테스트 경험을 정리합니다.

> 자동차 방탈출과 HYUNDAI MERGE의 소스가 포함되어 있습니다. 카트레이싱은 소개 및 배포 링크만 제공하며, 원본 소스는 아직 포함하지 않았습니다. 각 프로젝트의 담당 역할과 제작 결과는 제작자가 제공한 설명을 기준으로 작성했습니다.

## 로컬 실행

Python 3이 설치된 환경에서 저장소 루트에서 실행합니다. 별도의 패키지 설치는 필요하지 않습니다.

```sh
python3 -m http.server 8000
```

브라우저에서 원하는 게임 경로를 엽니다.

- 자동차 방탈출: `http://localhost:8000/games/locked-car-escape/`
- HYUNDAI MERGE: `http://localhost:8000/games/hyundai-merge/`

자동차 방탈출은 HTML 파일을 직접 열어도 실행됩니다. HYUNDAI MERGE는 온라인에서 Matter.js 0.20.0을 CDN으로 불러오며, CDN에 연결할 수 없으면 내장 물리 엔진을 사용합니다.

[자동차 방탈출 소스와 조작 방법](games/locked-car-escape/) · [HYUNDAI MERGE 소스와 조작 방법](games/hyundai-merge/)

## 1. 내 차에서 나 좀 꺼내줘!

자동차 내부에 숨겨진 단서를 찾고 3개의 퍼즐을 순서대로 해결해 탈출하는 웹게임입니다. 레이싱 중심의 자동차 게임에서 벗어나 추리와 코미디를 함께 즐기는 경험을 기획했습니다.

### 담당한 일

- 자동차 방탈출 아이디어 제안, 코미디 분위기의 스토리와 3단계 퍼즐 기획
- ChatGPT를 활용한 스토리·퍼즐 구체화 및 HTML, CSS, JavaScript 기반 제작
- 브라우저 플레이를 통한 UI 및 조작 방식 점검

### 피드백과 개선

초기에는 상호작용 버튼이 지나치게 눈에 띄어 탐색의 재미가 부족하다는 피드백을 받았습니다. 별도 버튼을 제거하고, 사물 위에 마우스를 올리면 테두리가 빛나도록 변경했습니다. 백미러 클릭으로 뒷좌석 시점으로 전환하도록 구성하고, 과도한 힌트를 줄여 직접 단서를 찾도록 개선했습니다.

**사용 기술:** HTML, CSS, JavaScript, Hover·Click 이벤트, ChatGPT

**결과:** 사물 중심 상호작용과 시점 전환을 갖춘 3단계 방탈출 게임 제작. 실제 플레이 인원과 평균 탈출 시간은 미측정입니다.

**연결 역량:** 사용자 요구 분석, 피드백 반영, UI/UX 개선

## 2. HYUNDAI MERGE

현대자동차 차종을 수박게임의 합성 구조에 적용한 웹게임입니다. 같은 차량을 합성하면서 새로운 차종을 발견하고, 최종 단계인 유니버스 완성을 목표로 합니다.

### 담당한 일

- 9종 차량과 8개의 합성 관계로 구성된 성장 구조 기획
- 승용차, SUV, 승합차, 트럭, 버스 등 외형이 구분되는 차종 선정 및 이미지 수집
- 가까운 단계에서 혼동하지 않도록 2단계 이내 차량에 서로 다른 색상 적용
- 차량별 등장 확률, 합성 점수, 충돌체 크기, 게임오버 조건 정의
- 말·폭탄·다운그레이드 아이템 3종의 효과와 등장 조건 구체화
- ChatGPT를 활용한 규칙 설계 및 웹게임 제작

### 구현 및 점검

HTML5 Canvas와 JavaScript, Matter.js로 중력 낙하, 차량 충돌, 합성 동작을 구현하고 실제 차량 이미지를 에셋으로 적용했습니다. localStorage로 최고 점수를 저장하도록 구성했습니다. 동일 차량 합성, 최종 단계의 추가 합성 방지, 아이템 효과를 코드 수준에서 점검했습니다.

**사용 기술:** HTML5 Canvas, JavaScript, Matter.js, localStorage, ChatGPT

**결과:** 9단계 성장 구조와 특수 아이템 3종을 포함한 합성 게임 제작. 실제 플레이 인원과 최고 점수는 미확인입니다.

**연결 역량:** 시스템 규칙 설계, 예외 조건 정의, SW 로직 검토

## 3. 인제 카트레이싱

팀원 병준님이 제작한 3D 카트레이싱 게임을 발전시킨 팀 프로젝트입니다. 플레이어 1대와 AI 차량 2대가 3바퀴 동안 경쟁하며, 부스터와 상대 방해 아이템으로 역전을 노립니다.

### 담당한 일

- 실제 플레이를 통한 주행 속도감, AI 주행, 충돌 반응, 난이도 테스트
- 개선 의견 정리 및 팀원에게 전달
- 몰입감과 속도감을 높이기 위한 효과음 선정
- 최종 팀 발표, 게임 규칙·아이템 소개 및 실제 플레이 시연

### 발견한 개선 사항

1. 주행 중 체감 속도감이 부족함
2. AI 차량이 뒤에서 충돌하면 플레이어 차량이 앞으로 밀리는 현상
3. AI의 낮은 주행 성능으로 인해 경쟁 난이도가 낮게 느껴짐

위 3가지 개선 사항을 팀원에게 전달했습니다. 피드백 반영 여부와 반영 후 측정 결과, 실제 플레이 인원은 미확인입니다.

**활용 도구·방법:** 3D 게임 직접 플레이, 효과음 자료 선정, 팀원과 의견 공유, 게임 화면을 활용한 발표·시연. 게임 엔진과 구체적인 개발 도구는 확인되지 않았습니다.

**결과:** 팀 프로젝트의 테스트, 효과음 선정, 발표 및 시연 담당. 기본 게임 제작은 팀원이 수행했습니다.

**연결 역량:** SW 테스트 및 검증, 예상과 다른 시스템 동작 발견, 개선 의견 전달

## 소스 및 에셋

HYUNDAI MERGE는 업로드된 원본 ZIP에서 가져왔으며, 게임 코드는 변경하지 않았습니다. 자동차 방탈출은 업로드된 단일 HTML 원본을 `games/locked-car-escape/index.html`로 이름만 변경해 추가했습니다. 카트레이싱 소스는 원본 확보 후 추가할 예정입니다. 차량 이미지와 효과음 등 외부 에셋은 배포 가능한 범위와 출처를 확인한 후 포함합니다. 현재 별도의 오픈소스 라이선스는 지정하지 않았습니다.
