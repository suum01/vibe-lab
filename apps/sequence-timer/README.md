# 차례차례 타이머

할 일과 예상 시간을 순서대로 입력하고, 하나씩 집중하는 Windows 설치형 앱입니다. 브라우저를 열어둘 필요가 없습니다.

예: 지원서 작성 40분 → 휴식 10분 → 코딩 공부 50분. 각 시간이 끝나면 소리와 Windows 알림을 보내고 다음 순서를 자동으로 시작합니다. 시간 종료는 실제 작업 완료 여부와는 별개입니다.

## 기능

- 할 일 추가·수정·삭제, 순서 변경, 1~1440분 예상 시간 입력
- 시작, 일시정지·재개, 5분 연장, 다음으로 넘기기, 진행 초기화
- 단계 종료 및 전체 종료 알림, 알림 테스트
- 창을 닫아도 시스템 트레이에서 계속 실행. 트레이 우클릭 → 완전히 종료
- 목록은 이 컴퓨터의 앱 데이터 폴더에 저장. 계정과 서버 연결 불필요
- 앱 재실행 시 목록은 복원되며 타이머는 시작 전 상태로 돌아갑니다

## Windows 설치 파일 받기

1. 저장소의 **Actions → Build Windows Timer**에서 최신 실행을 엽니다. 자동 실행되지 않았다면 Run workflow로 실행할 수 있습니다.
2. 빌드가 성공하면 아래 **Artifacts → sequence-timer-windows**를 다운로드합니다. GitHub 로그인이 필요할 수 있습니다.
3. ZIP을 풀고 `.exe` 설치 파일을 실행합니다.

Windows 빌드가 성공해야 설치 파일이 생성됩니다. 소스 폴더만 다운로드해서는 앱이 설치되지 않습니다. 현재 인증서로 서명하지 않으므로 Windows가 게시자를 확인할 수 없다는 표시를 할 수 있습니다.

## 사용 시 확인

처음 실행하면 **알림 테스트**로 소리와 알림 표시를 확인하세요. Windows 설정에서 앱 알림을 허용하고 방해 금지 설정을 확인해 주세요.

컴퓨터 종료·앱 완전 종료·절전 중에는 알림을 보낼 수 없습니다. 절전에서 돌아오면 경과 시간을 반영해 순서를 진행하고 마지막으로 지난 단계의 알림 하나를 표시합니다. 여러 단계가 지난 경우 현재 단계 또는 전체 종료 상태로 이동합니다. 진행 중 목록을 수정하려면 먼저 초기화해야 합니다.

## 개발 및 빌드

Node.js 22 이상과 npm이 필요합니다. Windows에서 다음을 실행합니다.

```sh
cd apps/sequence-timer
npm ci
npm test
npm start
```

Windows 설치 파일 생성:

```sh
npm run dist:win
```

`dist/`에 NSIS 설치 파일이 생성됩니다. GitHub Actions도 같은 명령으로 Windows에서 빌드합니다.

## 구조

- `timer.cjs`: UI와 분리된 시간·상태 관리. 마감 시각 기준 계산으로 백그라운드 지연과 절전 후 시간 보정
- `main.cjs`: Electron 앱, 트레이, 네이티브 알림, 로컬 파일 저장
- `preload.cjs`: 제한된 IPC 연결. 렌더러의 Node.js 접근 차단
- `index.html`, `style.css`, `renderer.js`: 외부 리소스 없이 실행하는 화면
- `test/timer.test.cjs`: 자동 전환, 종료, 일시정지, 연장, 건너뛰기, 절전 복귀, 입력 검증

## 검증 범위

- 타이머 로직 테스트 4개 통과: 자동 전환·종료, 일시정지·연장·건너뛰기, 절전 경과 시간 보정, 잘못된 입력 및 진행 중 수정 차단
- Linux 가상 화면에서 실제 Electron 앱으로 추가·수정·저장·시작·일시정지·연장·건너뛰기, 실시간 자동 전환·완료, 알림 명령과 창 닫기 후 프로세스 유지 확인
- Linux 디렉터리 패키징 통과
- Windows 설치 프로그램 실행, 실제 Windows 알림 표시·소리는 이 Linux 환경에서 확인하지 않았습니다. Windows 빌드는 GitHub Actions 결과를 확인해야 합니다.
